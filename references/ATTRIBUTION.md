# Reference provenance
`tire-markings.txt` is original project-authored explanatory text. It links to NHTSA TireWise as further reading and does not redistribute webpage text, tables or images. Citations in the application identify the actual locally indexed notes, not an external page the model has not retrieved. Add PDFs/TXT only when you have permission; metadata keeps filename, PDF page and chunk ID. Uploaded references are private runtime data excluded from Git.

No real tire photograph is redistributed. Add a photo you took or have permission to use through Upload. `scripts/make_smoke_image.py` creates a clearly synthetic text target solely for OCR plumbing checks, not a real tire recognition benchmark.
